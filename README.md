# Здраво — медицинский портал

Демонстрационный сайт с отдельными кабинетами врача и пациента, регистрацией и записью на приём.

## Запуск

Требуется Python 3. Запустите сервер из папки проекта:

```powershell
python server.py
```

Откройте в браузере <http://127.0.0.1:8000/>.

Сервер создаёт локальную базу `doctors.sqlite3` при первом запуске. База и персональные данные игнорируются Git и не публикуются в репозитории.

## Страницы

- `/` — главная и каталог врачей
- `/patient/register` и `/patient/login` — регистрация и вход пациента
- `/patient/cabinet` — запись к врачу и управление визитами
- `/login` и `/cabinet` — вход и кабинет врача
